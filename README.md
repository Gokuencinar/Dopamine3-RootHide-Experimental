
# RootHide + Dopamine 3 integration (under development)

This branch is based on Dopamine 3.0.11 and contains an **experimental,
incomplete RootHide port**, disabled by default. Building the current code
does not produce a functional RootHide jailbreak.

See [PORTING.md](PORTING.md) for pinned sources, integration boundaries and
the static prerequisite check. Do not distribute this branch as a RootHide
release until device tests and packaging verification have passed.
